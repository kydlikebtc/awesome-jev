# Held for the weekly upkeep: what a run read and could not settle yet. One
# per line, with the reason after a `#`:
#
#   owner/name  # why — a discovery candidate (an owner/name, as in declined.txt)
#   slug        # why — a catalogued row (its slug in catalog.json)
#
# Holding decides nothing. A held candidate stays in the discovery queue under
# its own heading, so the scheduled drafting runs stop reading past it; a held
# row stays in the catalogue as it is. docs/review-queue.md#needs-person lists
# every line here. Since 2026-11-05 the next weekly upkeep settles each line by
# the rules in MAINTAINING.md ("Candidates a run cannot settle"): a row added
# or changed, a line in declined.txt, or nothing to do, and deletes its line in
# the same pull request. Nobody else is waited for. A line whose candidate is
# catalogued or declined is shown as settled until the upkeep deletes it.
JevBench/jevbench  # benchmark of whether decision models' probabilities stay coherent (50 laws over noul, choice and score), sent through POST /v1/systemone to 21 openly released models in Jev's shape; it never measures Jev, and its README says "Jev" names only the wire interface. Not an alternative (it serves no model) and not a comparison with Jev (rules 3, 4 and 6); rule 8
franckverrot/lev  # serves POST /v1/systemone (lev/api.py) from a copy of the catalogued jaredpalmer/kev with only the backbone swapped for a smaller open one and its own trained weights; its README compares it with Jev. Same code as a row (rule 2), or its own alternative as lev-openlair was (rule 3); rule 8
getcustomaise/customaise-mcp  # MCP server and CLI for the Customaise Chrome extension; it only tells the extension which decision provider to use (Jev, OpenAI or Gemini), and the extension, not in this repository, sends the request: no call site here (rule 1)
devexzh/jev-solver  # Rust library and CLI that solves reCAPTCHA v2 image grids: Jev judges each tile, and Rust clicks and verifies. Whether the catalogue lists CAPTCHA solvers is a scope question; rule 8
autremachine/bosco  # LAN load balancer for LLM machines that added a POST /v1/systemone route, forwarding Jev-shaped requests to local Jev-shaped models; it serves no model of its own and never calls Jev, so neither clearly an alternative nor out of scope (rules 3 and 6); rule 8
