# Held for the weekly upkeep: what a run read and could not settle yet. One
# per line, with the reason after a `#`:
#
#   owner/name  # why — a discovery candidate (an owner/name, as in declined.txt)
#   slug        # why — a catalogued row (its slug in catalog.json)
#
# Holding decides nothing. A held candidate stays in the discovery queue under
# its own heading, so the scheduled drafting runs stop reading past it; a held
# row stays in the catalogue as it is. docs/review-queue.md#needs-person lists
# every line here. Since 2026-11-05 the next weekly upkeep settles each line by
# the rules in MAINTAINING.md ("Candidates a run cannot settle"): a row added
# or changed, a line in declined.txt, or nothing to do, and deletes its line in
# the same pull request. Nobody else is waited for. A line whose candidate is
# catalogued or declined is shown as settled until the upkeep deletes it.
